# creator-match — 达人匹配评估 Skill（ZCode）

投前评估达人与项目目标、产品或热点的匹配度：给定**达人分析或拆解档案**，加上**项目目标**、**产品信息或热点信息**，输出精简匹配结论（达人名称 / 所属行业 / 是否匹配 / 选取原因）。

## 安装

把 `creator-match/` 文件夹放进 ZCode 的技能目录（任选其一）：

- 用户级：`~/.agents/skills/creator-match/SKILL.md`（所有会话可用）
- 项目级：`<项目>/.agents/skills/creator-match/SKILL.md`

## 评估逻辑（三维，缺一不可）

| 维度 | 问题 | 检查点 |
|---|---|---|
| 调性 | 人对不对 | 人设与变现射程、风格细节、商业口碑、购买预期、风险（竞品/合规/争议） |
| 数据 | 盘子对不对 | 人群重合、量级与趋势、数据真实性、转化能力与预算匹配 |
| 内容 | 接不接得住 | 赛道距离、形式适配、生产能力、目标承接、热点专项 |

结论三选一：**匹配 / 勉强匹配 / 不匹配**，由硬伤决定而非平均分：任一维度 ≤2 分封顶"勉强匹配"，两个及以上 ≤2 分直接"不匹配"。

## 配套技能

- `creator-remix`：拆解达人、按模板产出分镜脚本。本技能只做匹配判断，确认要做内容后转给它。
- 达人拆解档案存放在工作区 `creators/<达人名>/拆解档案.md`，本技能优先读取。
