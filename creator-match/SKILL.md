# 达人匹配评估

投前闸门：在"拆解达人"和"写内容"之间，判断这个达人该不该投、这个热点能不能蹭。

流程：备齐三要素 → 三维评估 → 精简结论（达人名称 / 所属行业 / 是否匹配 / 选取原因）。

与 creator-remix 的分工：creator-remix 负责"拆达人、写内容"；本技能只负责"判断匹配与否"。用户看完评估要产出内容时，转 creator-remix 的产出流程，不要自己写脚本。

## 第一步：备齐三要素

| 要素 | 从哪来 | 缺了怎么办 |
|---|---|---|
| 达人分析 | 优先读工作区 `creators/<达人名>/拆解档案.md`；用户直接粘贴的达人分析文字也可用 | 停下来向用户要，或建议先跑 creator-remix 拆解。没有分析依据就不评估——凭印象判断等于算命 |
| 项目目标 | 用户口述：品牌曝光 / 种草转化 / 直播带货 / 私域获客 / 账号冷启动等，有预算量级和 KPI 就一并记录 | 必须先问。同一个达人做曝光可能匹配、做转化可能不匹配，目标缺失就无法评估 |
| 产品信息或热点信息 | 产品：品类、核心卖点、价格带、目标人群；热点：热点内容、当前传播阶段、与品类的关联 | 细节缺失就列为评估盲区，不要脑补 |

三要素是评估输入，不默认输出；要素齐全后直接给精简结论。评估中发现画像、互动量、商单记录等数据缺口时，先按【数据补全：飞瓜抓取】补实证再评，能补的不停在推断上。

## 第二步：三维评估

每个维度的判断都必须指回达人分析里的具体字段或原文。评语里出现"粉丝质量高、调性比较搭"这类没有出处的空话等于没评。

三维本质优先级差别不大，但缺一不可：任何一维是硬伤，另外两维再高分也补不回来，评估时不做跨维度补偿。

1. **调性（人对不对）**：达人的人设、风格、价值观与品牌/产品的气质是否相容，粉丝为什么信"他"推荐"这个"。
   - 人设与变现射程：对照档案"人设一句话"和"变现方式"——产品落在既有变现射程内是加分（测评博主接新品牌）；落在射程外又没有连接点就是人设透支（探店博主教编程课）。
   - 风格细节：语言风格（口语/书面/玩梗密度）、视觉调性（精致/真实感/粗粝）、价值观倾向，对照品牌形象查冲突点。
   - 商业口碑：达人过往商单的评论区反应——被夸"良心推荐"还是被骂"恰烂钱"，是调性容错度最直接的读数。
   - 购买预期：评论区高赞里频繁出现"求链接""多少钱"，说明粉丝有在他这里买东西的预期。
   - 风险：竞品合作痕迹、敏感品类与平台合规、过往争议记录——调性冲突和风险问题本质都是"这个人能不能碰"。
2. **数据（盘子对不对）**：粉丝画像、量级与转化能力能否支撑项目目标。
   - 人群重合：粉丝画像与目标人群对齐年龄、性别、城市线级、消费力、使用场景。档案没有画像数据就标"无法判断"，从高频选题和评论区高赞侧面推断时必须注明是推断。
   - 量级与趋势：粉丝量、近期互动量级、数据处于上升期还是疲软期；要曝光但样本互动量级明显撑不起目标，是划不来的信号。
   - 数据真实性：高赞低评、评论内容与视频无关、粉丝量短期突增都是刷量迹象——先扣真实性，再谈重合度。
   - 转化能力：有无挂车/直播/导购组件及实际转化记录；报价与预算的匹配度，按粉丝单价折算是否高于同量级行情。
3. **内容（接不接得住）**：达人的内容能否自然装下这个产品或热点，并导向项目目标。
   - 赛道距离："高频选题"与产品品类的距离——近赛道（护肤达人×美妆工具）直接成立；跨赛道要找连接点（场景、人群、动机任一讲得通），连接点讲不通就不硬接。
   - 形式适配：达人的内容形式（口播/剧情/测评/混剪/vlog）与产品卖点的展示方式是否匹配——要讲成分配混剪型、要演示场景配口播型，错配则卖点装不进去。
   - 生产能力：更新频率、质量稳定性（爆款是偶发还是持续产出）、定制商单相对自然内容的数据落差。
   - 目标承接：要转化但达人内容纯情绪向、没有挂车/直播/评论区导购组件，是硬伤。
   - 热点专项：热点是否在达人赛道射程内、生命周期还剩几天（过了峰值就不值得投）、达人惯用内容形式接不接得住（慢节奏 vlog 博主硬接快节奏梗是勉强）。

## 数据补全：飞瓜抓取

三维评估里最容易缺的是数据维实证（画像、互动、商单）。有浏览器环境时，优先抓飞瓜补全，而不是停在推断：

1. **前提**：browser-use 可用；飞瓜需要登录+会员（抖音版 `https://dy.feigua.cn/`，B站达人走 `https://bz.feigua.cn/`）。先开首页检查登录态：未登录就请用户在应用内浏览器窗口里自行登录（扫码或账密），登录态会保留在会话里，之后复用。不要索要或代替用户输入密码。
2. **抓取路径**：站内搜索达人名 → 进达人详情页 → 用 domSnapshot 读取：粉丝数、性别比、年龄分布、地域分布、活跃度、近 30 天互动中位数（赞/评/转）、带货力与商单记录。飞瓜某模块在会员墙外抓不到，就如实标注缺口，不要硬抓、不要编数。
3. **写回档案**：抓到的数据更新进 `creators/<达人名>/拆解档案.md`——"待补充"里对应项转正，标注"飞瓜，采集日期"。档案是活的，下次评估直接用。
4. **降级**：没有浏览器环境、用户不登录、或飞瓜无该达人收录时，维持推断口径，并在选取原因里保留缺口半句。

## 第三步：出结论

- 结论三选一：**匹配 / 勉强匹配（有条件可做）/ 不匹配**。不和稀泥，"总体还行"不是结论。
- 每个维度 0-5 分，总分取平均。但结论由硬伤决定，不由平均分决定：任一维度 ≤2 分，最高只能给"勉强匹配"；两个及以上维度 ≤2 分，直接"不匹配"。
- 证据优先级：档案/分析原文 > 用户口述 > 行业常识。每条判断都要能指回来源。
- 信息缺口不默认输出：缺口直接影响结论时，在选取原因里用半句点出（如"画像缺失、价位匹配未实证"），待补清单留在内部，用户追问时展开。
- 建议浓缩为选取原因的最后一句：匹配给切入角度（哪个卖点 × 达人哪个惯用结构或钩子句式），勉强给条件，不匹配给"该找什么样的达人"。

## 输出格式

三维评估照常执行（打分、证据核对都在内部完成），但对用户默认只输出四项精简结论：

```markdown
- **达人名称**：李杰杰杰克
- **所属行业**：创意Vlog / 生活科普（剪辑师出身，强视觉叙事）
- **是否匹配**：匹配（4.2/5）
- **选取原因**：人设"以摄影的视角探索极致的世界"与 AI 眼镜"第一视角主动记忆"的核心卖点天然咬合，产品能当内容工具而不是广告道具；有 3C 商单先例，粉丝对广告已有预期。扣分在更新低频（单条难沉淀持续心智）和粉丝画像缺失（价位匹配未实证）。建议以"产品即工具"的定制 Vlog 切入，弱开箱测评、强场景叙事。
```

- 选取原因写 2-4 句：先给决定性依据（哪个维度定了结果，引档案原文为证），勉强匹配要带条件，不匹配要带"该找什么人"，最后一句给切入建议。
- 维度得分只以均分形式出现在"是否匹配"后的括号里；分维度表、硬伤与缺口、要补的信息不默认输出，用户追问"为什么/细节"时再展开完整版。
- 内部标准不降：每个判断仍必须指回达人分析原文，只是证据浓缩进选取原因，不铺开成表。

## 多达人对比

用户给了多份档案或多篇分析时，用同一套三维评估逐个跑，输出一张四列表（达人名称 / 所属行业 / 是否匹配 / 选取原因），按匹配度从高到低排，表尾一行点名首选与备选。对比的重点是差异，选取原因里要写清"为什么选他而不是别人"。不要给每个达人写一篇等长的独立报告。

## 反向模式：还没有具体达人

用户只有产品或目标，问"该找什么样的达人"时，从三维倒推一份选人标准：目标人群 → 找什么画像；品类 → 找什么赛道；项目目标 → 要什么内容形式与变现组件；预算量级 → 什么粉丝量级。输出的是筛选标准清单，不是虚构某个具体达人。

## 边界

- 只判断，不产出内容。用户确认要做内容后转 creator-remix。
- 没有达人分析不评估，先引导拆解或请用户粘贴分析。
- 档案有采集日期：超过 1 个月提醒数据可能过期，重大投放决策建议补采。
- 评估是决策依据，不是结果保证；投不投最终是用户的商业决策。
